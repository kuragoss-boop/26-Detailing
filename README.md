# Twenty-Six Detailing Website

## Starten
1. Ordner in Visual Studio Code öffnen.
2. Erweiterung "Live Server" installieren.
3. `index.html` öffnen.
4. Unten rechts auf "Go Live" klicken.

## Vor Veröffentlichung ersetzen
- Telefonnummer `+49 000 0000000`
- WhatsApp-Link `490000000000`
- E-Mail-Adresse
- Impressumsangaben
- Datenschutzerklärung
- Musterbewertungen
- Einsatzgebiet
- echte Logo-Datei, falls vorhanden

## Hosting
Das Kontaktformular ist für Netlify Forms vorbereitet (`data-netlify="true"`).
